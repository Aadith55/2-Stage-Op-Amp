# Simulation results

Store results generated by rerunning the circuit in LTspice here. The numbers in `docs/design-report.md` are copied from the supplied report and are not independent verification.

For each final run, record:

- LTspice version and model-library source/version (without redistributing restricted files).
- Supply, input common-mode voltage, input AC magnitude, and load capacitance.
- Analysis directive and frequency/time range.
- Selected compensation resistance `Rz`.
- Measured open-loop DC gain, unity-gain bandwidth, phase margin, and how each was read.
- Whether results are simulated or measured on hardware.

Place readable plot exports in `figures/`. Keep screenshots cropped to the relevant plot and include axis labels, trace legends, and cursor/readout values when they support the stated measurements.
